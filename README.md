# DirectX 2D Polygon Game

A simple 2D game built using DirectX 9, featuring polygon character movement and animation. The game supports keyboard controls (WASD) for moving the character, with real-time updates and collision detection.

## Features
- **2D Polygon-Based Character**: The main player is represented by a polygon that can be moved across the screen.
- **Smooth Character Animation**: The polygon character is animated using sprite sheets, with different animations for movement directions.
- **Keyboard Controls (WASD)**: Use the W, A, S, and D keys to move the character in four directions (up, down, left, and right).
- **Boundary Collision**: The character cannot move outside the screen boundaries, ensuring smooth gameplay.
- **Real-Time FPS Display**: The frames per second (FPS) are displayed in real-time on the top-left corner of the screen.
- **Physics-Based Movement**: The game includes basic physics such as inertia and acceleration, enhancing the realism of movement.

## Controls
- **W** - Move up
- **A** - Move left
- **S** - Move down
- **D** - Move right
